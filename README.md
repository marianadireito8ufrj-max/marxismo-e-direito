# Caderno Digital — Ética Profissional e Estatuto da Advocacia

Caderno digital da disciplina de Ética Profissional e Estatuto da Advocacia — FND/UFRJ, 8º período, semestre 2026.2.

A interface usa como base estrutural o projeto `marxismo-e-direito`, adaptado para a identidade visual em vinho, rosa queimado e tons claros do caderno-base da disciplina.
